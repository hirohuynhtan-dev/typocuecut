# Typo Cuecut — Talking-Head Typography & Auto SFX Studio for CapCut

Công cụ thiết kế chữ chuyển động  và tự động gắn hiệu ứng âm thanh (**Auto SFX**) chuyên biệt cho video Talking-Head trên **CapCut Desktop (macOS Apple Silicon M1 / M2 / M3 / M4)**.

## Tải về cho macOS (Apple Silicon `arm64`)

https://github.com/hirohuynhtan-dev/typocuecut/releases/download/v1.0.1/Typo.Cuecut-1.0.1-arm64.dmg

> **Tự động cập nhật:** Bộ cài `.dmg` chứa đầy đủ app + kho 576 âm thanh SFX. Ngay sau khi cài và mở ứng dụng lần đầu, **Typo Cuecut** sẽ tự động kiểm tra và nhắc bạn nâng cấp lên phiên bản mới nhất (`v1.0.2+`) ngay trong ứng dụng chỉ với gói cập nhật ~2 MB.

---

## Hướng dẫn cài đặt nhanh

1. Mở file `.dmg` vừa tải -> kéo biểu tượng **Typo Cuecut** thả vào thư mục **Applications**.
2. **Nếu macOS báo chặn khi mở lần đầu (Gatekeeper):**
   - **Cách 1 (Chuột phải):** Mở thư mục `Applications` -> nhấp **Chuột phải (Control + Click)** vào `Typo Cuecut` -> chọn **Open** -> bấm **Open**.
   - **Cách 2 (Terminal nếu báo "damaged" / "không thể xác minh"):** Mở Terminal và chạy lệnh:
     ```bash
     xattr -cr "/Applications/Typo Cuecut.app"
     ```
3. Mở app và sử dụng!

---

## Tính năng chính
- **2 chế độ giao diện:** Tối mặc định (chuẩn CapCut) & Sáng (chuẩn macOS).
- **24 Preset Typography tiếng Việt** dựng sẵn + **15 bố cục thông minh** (tự né vùng khuôn mặt).
- **Kho 576 hiệu ứng âm thanh (SFX)** tích hợp sẵn, tự động khớp nhịp chữ.
- **Xuất an toàn sang CapCut:** Nhân bản dự án thành `TC - <Tên dự án>`, giữ nguyên 100% dự án gốc.
